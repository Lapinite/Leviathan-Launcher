# Leviathan Launcher

Leviathan Launcher is a third-party desktop launcher for **Minecraft: Java Edition**.

The launcher is designed for legitimate Minecraft owners and provides a modern launcher experience with Microsoft account authentication, player profiles, launcher customization, cosmetics, and additional quality-of-life features.

> **Project Status:** Private Development

---

## About Leviathan Launcher

Leviathan Launcher is an independent Minecraft: Java Edition launcher focused on providing a modern, customizable, and user-friendly desktop experience.

Users authenticate using their own Microsoft account, and Minecraft ownership is verified through the official Microsoft, Xbox Live, XSTS, and Minecraft Services authentication systems.

Leviathan Launcher does not bypass Minecraft authentication, licensing, ownership checks, or Microsoft account security.

A valid Microsoft account with legitimate access to Minecraft: Java Edition is required to play.

## Microsoft Authentication

Leviathan Launcher uses Microsoft's official authentication infrastructure to securely authenticate users.

The authentication process uses:

1. Microsoft OAuth
2. Xbox Live authentication
3. Xbox Security Token Service (XSTS)
4. Minecraft Services
5. Minecraft ownership and profile verification

Users enter their Microsoft credentials directly through Microsoft's authentication system.

Leviathan Launcher does **not** request, receive, or store Microsoft account passwords.

The launcher uses a Microsoft Entra registered public desktop application for authentication.

No confidential client secret is embedded in the launcher.

---

## Minecraft Ownership

Leviathan Launcher is intended only for users who legitimately own Minecraft.

Before allowing a user to launch Minecraft, the launcher uses Minecraft Services to verify that the authenticated Microsoft account has access to Minecraft: Java Edition.

Leviathan Launcher does not provide:

- Cracked authentication
- Offline account impersonation
- Minecraft ownership bypasses
- License bypasses
- Authentication bypasses
- Account sharing systems
- Unauthorized account access
- Circumvention of Microsoft or Mojang security systems

Users are responsible for using their own legitimate Microsoft and Minecraft accounts.

---

## Security

Security is an important part of Leviathan Launcher.

The launcher is designed so that:

- Microsoft passwords are never handled directly by the launcher
- Authentication takes place through Microsoft
- No Microsoft client secret is distributed with the desktop application
- Authentication tokens are used only where necessary for Microsoft, Xbox, XSTS, and Minecraft Services
- The launcher does not attempt to bypass Microsoft security systems
- Minecraft ownership is verified before launching the game
- Users authenticate through official Microsoft login systems
- Authentication-related testing is currently performed only by the developer

Users should never provide their Microsoft password directly to Leviathan Launcher or to anyone claiming to represent the project.
