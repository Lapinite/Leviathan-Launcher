# Leviathan Launcher Installation

**Status:** Not Publicly Available

Leviathan Launcher is currently in private development.

There is currently no official public installer, download, beta build, or release package.

---

## Current Access

Development builds are currently restricted to authorized maintainers of the **Leviathan project portfolio**.

The project repository is public for documentation, transparency, and review purposes, but the launcher itself is not currently distributed publicly.

---

## Official Downloads

There are currently **no official public downloads**.

Do not trust third-party sites claiming to distribute an official public Leviathan Launcher build during this private-development stage.

The official project repository is:

https://github.com/Lapinite/Leviathan-Launcher

## Security

Before downloading any future public release:

- Verify it comes from an official Leviathan source.
- Do not enter Microsoft passwords directly into unofficial launcher forms.
- Do not run unofficial or modified installers claiming to be Leviathan Launcher.
- Review release notes and security announcements where available.

See [SECURITY.md](../SECURITY.md).
