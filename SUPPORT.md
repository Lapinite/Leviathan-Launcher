## Security Issues

Do not report security-sensitive vulnerabilities through ordinary public support channels.

Please follow [SECURITY.md](SECURITY.md).

Never post:

- Passwords
- Access tokens
- Refresh tokens
- Session cookies
- Client secrets
- Private keys
- Recovery codes
- Personal authentication data
